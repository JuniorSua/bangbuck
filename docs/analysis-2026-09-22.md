publishes current data. Claude Opus 5.5, GPT-6 Sol and GPT-6 Luna launched today; none is measured
by DeepSWE or rated on Arena WebDev yet.

## What changed in the snapshot

- **GPT-6 Astra is 27–39% cheaper per task on DeepSWE.** Pass rates, tokens and steps are identical.
  The Sept 3 run was "priced at the expected launch rate card", which added a compute-unit fee.
  The new cost basis is OpenAI's actual list price ($10 input / $1 cached / $12.50 cache write /
  $50 output per M, no compute-unit fee). Recomputing Astra medium from its published token counts
  gives $3.075, matching DeepSWE's figure. OpenAI's page still lists a long-context rate
  ($20/$75); DeepSWE applies the short-context rate at all lengths, so heavy long-context use
  could cost somewhat more.
- Arena WebDev added grok-4.7-xhigh, claude-fable-5-high, deepseek-v4.1-flash-max and mimo-v2.6-pro.
  Fable 5 high now matches its WebDev rating directly instead of borrowing a family entry.

Terminal-Bench's own cost column agrees with BangBuck's direction: Astra reaches Fable 5.1's score
at roughly half the cost per task (xhigh $7.12 vs $14.76), and Astra medium/low give the most
accuracy per dollar among strong entries.

Opus 5.5 leads Anthropic's own table (Terminal-Bench 4.0 66.4%) and Artificial Analysis' general
index, but Artificial Analysis measured 59.6% on Terminal-Bench 4.0, level with Astra. It is cheaper
per token ($4/$20) yet generated 260M output tokens on that index against Astra's 60M, costing
$8,708 vs $5,324 to evaluate. Until DeepSWE measures it, its value per coding task is unknown; the
token appetite is the number to watch.

The page lists Opus 5.5, GPT-6 Sol and GPT-6 Luna as "too new to measure" (`lib/notes.ts`); each
entry retires itself once DeepSWE publishes a configuration for it.
